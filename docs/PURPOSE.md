# Purpose

**GitHub-Boss-Pro** is a phone-first Android tool to make **GitHub** and **Termux** workflows easier when you are away from a laptop.

## Goals

- Authenticate with a GitHub Personal Access Token
- Browse and manage repositories from the phone
- Support common GitHub tasks (issues, workflows, notifications, search, create repo) as they are approved and migrated
- Stay clean, secure, and buildable in CI (AAB for Play Store)
- Play nicely with Termux-based development on Android

## Out of scope

- AI avatars / character systems
- Aura-Studio or Mandela-Matrix features
- Desktop-first complex IDE replacement

Feature work stays frozen until explicitly approved.
