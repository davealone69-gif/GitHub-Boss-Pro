# Coding Tips (local memory)

This is **not** on-device ML training.

You save tips from real work (build fixes, Termux tricks, API gotchas).
Help coach can surface matching tips and inject them as context.

## In the app

Help tab → **Coding tips** section:
- Add title + body (+ optional tags)
- List / delete
- Tips appear when you Ask help (appended under the answer when relevant)

## Good tip examples

- "Gradle wrapper missing → curl jar from gradle v8.9"
- "PAT 401 → check repo + workflow scopes"
- "Gemini 429 → wait or use free template"
- "adb install path on Termux"

Keep tips short and actionable.
